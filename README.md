## 📌 Project Overview

> A hands-on **Flutter CRUD Application** built as part of my mobile development learning journey.
> This project gave me practical experience in building cross-platform apps, working with Firebase,
> and applying real-world Flutter concepts — while working through real challenges along the way.

---

## 🏗️ What I Built

<div align="center">

| 🗂️ Feature | 📋 Description |
|:---:|:---|
| **Create** | Add new records via validated input forms |
| **Read** | Fetch and display data from Firebase in real time |
| **Update** | Edit and save changes to existing records |
| **Delete** | Remove records securely from the database |
| **Firebase Integration** | Cloud-based backend with real-time data sync |
| **Form Validation** | Input error handling and data integrity checks |
| **Responsive UI** | Clean, mobile-first interface using Flutter widgets |

</div>
